Crystal Viewer — Demo Index

  • Basic Embedding (M7) — Plain-HTML Web Component embedding with two independent instances
  • Programmatic Controls & Events (M7) — Controls synchronized through events, with state save/restore
  • Fluorite (M2) — Cubic mineral with form-development sliders and habit selection
  • Quartz (M3) — Trigonal mineral with habits, handedness selection, face picking, and Miller-Bravais indices
  • Minerals (M5) — Multi-mineral demo with mineral and habit selection, crystal-system and setting info, and face picking
  • Minerals with HDRI (M5 variant) — User-uploaded HDR/EXR lighting with three-axis orientation, exposure, tone mapping, and background-only zoom
  • Atomic Structure (M6) — CIF import, symmetry expansion, periodic bonds, lattice repetition, and view-mode controls
  • CIF Morphology — Render measured external crystal faces or an identified theoretical BFDH-style fallback
  • Appearance (M8) — Quartz, fluorite, and pyrite reference scenes with synchronized appearance controls (color, roughness, metalness, transmission, IOR, absorption)
  • Surface Baseline (SR0) — Fixed lighting, camera, exposure, and output size for all current minerals
